Welcome

You have successfully reached the EaseVote API service. This API handles user authentication, event management, voting, ticketing, USSD interactions, and payment processing.

Base URL: https://api-dev.easevotegh.com/api

Core Modules

  • Events: Manage voting and ticketing events
  • Purchasing: Process payments via Mobile Money, Card, and USSD
  • USSD: Direct integration with NALO and Apps&Mobile
  • Ticketing: Generate, send, and verify QR-code tickets
  • Notifications: SMS and Email receipts for users
